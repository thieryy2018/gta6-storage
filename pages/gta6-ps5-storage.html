PS5 Storage Guide

Best PS5 SSD for GTA 6

GTA 6 is 210GB and launches November 19. PS5 games cannot run from USB drives, you need an internal M.2 SSD. Here is exactly what to buy and why.

Important: External USB Will NOT Work for GTA 6 on PS5

Sony's official support documentation states: "PlayStation 5 games cannot be played directly from USB extended storage." This means no USB SSD, no USB HDD, and no USB hub solution will let you run GTA 6. You need either the PS5's internal storage or an M.2 NVMe SSD installed in the expansion bay.

What PS5 Storage Options Actually Exist

Internal M.2 SSD

Installed in the PS5 expansion bay. Fully supports GTA 6. Requires PCIe Gen 4, NVMe, heatsink. Recommended upgrade path.

USB Extended Storage

PS4 games only. Can store/archive PS5 game data but cannot run PS5 games. Good for freeing up internal space.

USB for GTA 6?

Not possible. GTA 6 is a PS5 game. Sony does not allow PS5 games to run from USB storage, full stop.

How External USB Works on PS5 (and What It Cannot Do)

Sony allows USB extended storage on PS5, but with strict rules. Here is a plain-English breakdown:

1

Format the USB drive as extended storage

Plugging in a USB drive and formatting it as extended storage on PS5 is straightforward. Sony requires SuperSpeed USB (5Gbps minimum). Once formatted, the drive is dedicated, it erases everything on it.

2

Move PS4 games to USB, play them directly

You can install and play PS4 games (like GTA V, Red Dead Redemption 2, or any PS4 title) directly from the USB drive. This is the main use case, it frees up internal PS5 storage for new titles.

3

Archive PS5 game data to USB

You can copy PS5 game data (including GTA 6 once installed) to USB for archiving. When you want to play, copy it back to internal or M.2 storage. This takes time but avoids re-downloading large files.

4

GTA 6 cannot run from USB, full stop

GTA 6 is a PS5 game. Sony's rule is absolute: PS5 games cannot run from USB extended storage. No workaround exists. You must have enough internal or M.2 SSD space to install and play it.
